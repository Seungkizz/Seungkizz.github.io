# 김승기 포트폴리오

Java·Oracle 기반 결제중계 및 정산 서비스 개발 경험을 소개하는 정적 사이트입니다. 빌드나 패키지 설치가 필요하지 않으며 GitHub Pages에서 제공합니다.

## 로컬 확인

저장소 루트에서 `node scripts/serve.mjs`를 실행한 후 http://127.0.0.1:4173 에 접속합니다. 종료는 Ctrl+C입니다.

## 구성

- `index.html`: 소개, 프로젝트, 경력, 기술, 연락 섹션 및 SEO 메타데이터
- `css/style.css`: 색상·간격 토큰, 공통 카드, 반응형 및 접근성 스타일
- `js/career.js`: 익명화된 실무 경력 데이터
- `js/data.js`: 기존 개인·교육 프로젝트 데이터
- `js/main.js`: 공통 렌더링, 상세 대화상자, 필터, 타임라인, 내비게이션
- `404.html`: GitHub Pages 오류 페이지

## 콘텐츠 수정

경력은 `js/career.js`에서 수정합니다. 역할·기간·담당 업무·결과는 확인 가능한 자료만 사용하고 고객사명·내부 구성·인증정보는 넣지 않습니다. `featured: true`인 프로젝트가 기본 목록에 표시됩니다. 전체 목록과 타임라인, 상세보기는 같은 데이터를 사용합니다.

프로젝트 기간은 재직 기간과 구분합니다. 공개 경력 자료에 없는 기술 선택 근거, 수치 성과, 개인 회고는 추정하지 않습니다. 연락은 이메일(mailto)과 GitHub 링크를 제공합니다.

기술 분류는 `js/main.js`의 `stackGroups`에서, 디자인은 `css/style.css`의 `:root` 토큰에서 수정합니다. 새 프레임워크와 외부 JavaScript 라이브러리는 사용하지 않습니다. 한글 폰트는 Noto Sans KR이며 외부 폰트 연결 실패 시 시스템 폰트로 표시됩니다.

## 검증

- `node --check js/main.js`
- `node --check js/career.js`
- `node --check js/data.js`
- `git diff --check`

브라우저에서 모바일 메뉴, 프로젝트 필터·상세보기, Escape 닫기·포커스 복귀, 섹션 표시, 가로 넘침, 404 페이지를 확인합니다. 애니메이션 감소 설정에서는 등장 효과와 부드러운 스크롤이 해제됩니다.
